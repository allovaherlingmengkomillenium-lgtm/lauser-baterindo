# PT LAUSER BATERINDO GALA PRATAMA — Luxury Website

Website statis HTML + CSS, siap di-upload ke GitHub Pages.

## File
- `index.html` — halaman utama
- `style.css` — desain responsif
- `images/` — folder aset
- `README.md` — panduan

## Upload ke GitHub
1. Buat repository baru di GitHub, misalnya `lauser-baterindo`.
2. Upload `index.html` dan `style.css`.
3. Jika ada folder `images`, upload juga.
4. Buka **Settings → Pages**.
5. Source: **Deploy from a branch**.
6. Branch: **main** dan folder **/(root)**.
7. Klik **Save**.
8. Tunggu beberapa menit sampai URL GitHub Pages muncul.

## Catatan
Foto komoditas pada halaman memakai URL Wikimedia Commons agar website tetap ringan. Jika ingin seluruh gambar benar-benar tersimpan di repository, unduh foto yang sesuai dan ubah `src` pada HTML menjadi path lokal seperti `images/pinang.jpg`.

Email formulir saat ini menggunakan `info@lauserbaterindo.com` sebagai alamat contoh dari versi sebelumnya. Ganti di `index.html` bila alamat email perusahaan berbeda.
